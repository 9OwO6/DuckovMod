# Design Notes

## Original Problem

The default throwable workflow in Escape from Duckov felt restrictive during active gameplay.  
Switching between weapon use and throwable use created friction, especially when quick reaction mattered.

## Design Goal

The goal of BetterThrowingSystem was to reduce friction and improve the usability of throwable items without breaking the core gameplay loop.

## Main Design Considerations

- fast access to throwable items
- smoother switching behavior
- practical hotkey usage
- lower inventory friction
- configurable behavior for different player preferences

## Iteration Approach

This project evolved through repeated testing, gameplay validation, and AI-assisted exploration of possible implementation paths.

The design direction was shaped by:
- what felt better in actual gameplay
- what was technically practical in the game’s modding environment
- what players would realistically find useful

## Why This Project Matters

This mod is a good example of how I approach problems:
- identify friction
- define a better workflow
- iterate quickly with AI assistance
- validate in practice
- release something usable
